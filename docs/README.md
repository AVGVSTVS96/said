# README artwork

`header-light.png` and `header-dark.png` are the light/dark README header, rendered at 1676×480 for an 838-pixel column. The README selects them through a color-scheme `<picture>`. The header states the product name and the no-cleanup promise; it contains no benchmark measurement.

The artwork uses Instrument Sans and Courier Prime. Their full OFLs are retained in [licenses/fonts](../licenses/fonts), with credits in [NOTICE](../NOTICE). The app itself embeds Courier Prime for original recognition and uses system UI fonts elsewhere.
